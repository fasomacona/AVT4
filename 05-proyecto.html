Tema 4: Análisis y visualización de datos

4.5 Proyecto final y evaluación

Inicio 1. Organización 2. ETL 3. Modelado 4. Informes 5. Proyecto Ejercicios

Objetivo del proyecto

Desarrollar de extremo a extremo un caso de análisis organizacional: datos → Power Query → modelo → medidas DAX → informe Power BI → conclusiones.

Alcance mínimo sugerido

  1. Pregunta de negocio explícita (1 párrafo).
  2. Al menos 2 fuentes o 2 tablas que se combinen (hechos + dimensiones).
  3. Limpieza documentada en Power Query (tipos, nulos, columnas).
  4. Modelo en estrella con tabla de fechas y relaciones correctas.
  5. Al menos 5 medidas DAX (incluye una de inteligencia de tiempo si aplica).
  6. Informe con 3+ páginas: resumen ejecutivo, detalle, y una de análisis/exploración.
  7. Conclusiones y limitaciones (correlación ≠ causalidad cuando corresponda).

Ideas de dominio

  • Ventas retail (ticket, producto, tienda, fecha).
  • Soporte / helpdesk (tickets por prioridad, agente, SLA).
  • Educación (inscripciones, carrera, periodo).
  • Operaciones (defectos, turno, línea de producción).
  • Datasets públicos (INEGI, datos.gob.mx, Kaggle) adaptados al modelo estrella.

Entregables

  • Archivo .pbix (Power BI Desktop).
  • Documento breve (2–4 páginas): pregunta, modelo (diagrama), medidas, hallazgos.
  • Presentación oral o video corto (opcional según rúbrica del docente).
  • Datos de origen o enlace + instrucciones de actualización.

Rúbrica orientativa

CriterioPeso sugerido
Claridad de la pregunta de negocio10 %
Calidad del ETL (Power Query)20 %
Modelo y relaciones20 %
Medidas DAX correctas y útiles15 %
Diseño del informe (UX, accesibilidad básica)20 %
Interpretación y limitaciones15 %

Cronograma sugerido (4 semanas)

  1. Semana 1: pregunta, datos, boceto del modelo.
  2. Semana 2: ETL + relaciones + primeras medidas.
  3. Semana 3: informe completo y validación de números.
  4. Semana 4: conclusiones, ensayo de presentación, entrega.
El notebook de práctica genera CSVs de ejemplo (hechos y dimensiones) para que puedas importarlos a Power BI y seguir el flujo completo sin depender de una base externa.
